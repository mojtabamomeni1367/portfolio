# momenimojtaba.com

سایت شخصی مجتبی مؤمنی. صفحهٔ اصلی `index.html` است و Cloudflare Pages هر تغییر این مخزن را خودکار منتشر می‌کند.

## اخبار (خودکار)
- هر ۳ ساعت، `scripts/fetch_news.py` خبرهای منابع `config/sources.json` را می‌خواند.
- خبرهایی که نام یکی از کشورهای نقشه در آن‌هاست (`config/countries.json`) در `data/news.json` ذخیره می‌شود.
- فقط عنوان، نام منبع، تاریخ و لینک ذخیره می‌شود. خواننده برای متن کامل به سایت منبع می‌رود.
- برای اضافه یا حذف یک منبع، فقط `config/sources.json` را ویرایش کنید.
- برای به‌روزرسانی فوری: Actions ← Update news ← Run workflow.

## تحلیل‌ها

### پنل ویرایش (پیشنهادی)
1. به [app.pagescms.org](https://app.pagescms.org) بروید و با حساب GitHub وارد شوید.
2. مخزن `portfolio` را باز کنید و بخش «تحلیل‌ها» را انتخاب کنید.
3. برای ویرایش روی یک تحلیل کلیک کنید، تغییرات را بدهید و **Save** بزنید. برای تحلیل جدید **Add** را بزنید.
4. یکی دو دقیقه بعد، تغییر روی سایت دیده می‌شود.

### امتیاز سئو
صفحهٔ [momenimojtaba.com/seo](https://momenimojtaba.com/seo/) را در زبانهٔ دیگری کنار پنل باز نگه دارید. پس از هر Save، ظرف حدود ۲۰ ثانیه امتیاز سئو و خوانایی و فهرست ایرادها به‌روز می‌شود. این صفحه در گوگل نمایه نمی‌شود.

### ویرایش مستقیم فایل‌ها
1. یک فایل `.md` در پوشهٔ `content/analyses/` بسازید (از روی `_template.md`).
2. برای هر زبان یک فایل جدا بسازید و `slug` همهٔ نسخه‌ها را یکی بگذارید.
3. با ذخیرهٔ فایل، صفحهٔ تحلیل ساخته می‌شود و روی نقشه و در Top Stories نمایش داده می‌شود.
4. اگر `draft: true` باشد، تحلیل منتشر نمی‌شود.

## ساختار
```
index.html                 صفحهٔ اصلی
assets/                    عکس، تصویر پس‌زمینه، رزومه
data/news.json             خبرها (خودکار)
data/analyses.json         فهرست تحلیل‌ها (خودکار)
analysis/                  صفحه‌های تحلیل (خودکار)
content/analyses/          متن تحلیل‌های شما
seo/                       صفحهٔ بررسی سئو
.pages.yml                 تنظیمات پنل ویرایش (Pages CMS)
config/                    منابع خبری و کلیدواژه‌های کشورها
scripts/                   اسکریپت‌های خبرخوان و سازندهٔ تحلیل
.github/workflows/         زمان‌بندی کارهای خودکار
```
